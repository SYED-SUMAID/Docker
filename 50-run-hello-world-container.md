# Run Hello World Container

## 1. Run Hello World

    sudo docker run hello-world

Downloads the `hello-world` image if it is not available locally and runs a container from it.

![alt text](<Screenshot (755)(1).png>)

## 2. List Docker Images

    sudo docker image ls

Shows the `hello-world` image that was downloaded.

![alt text](<Screenshot 2026-09-14 194244.png>)

## 3. List All Containers

    sudo docker container ls -a

Shows the `hello-world` container after it finishes running.

![alt text](<Screenshot 2026-09-14 194322(1).png>)
